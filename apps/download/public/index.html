Install instructions & build notes
  1. Download the APK and open it from Downloads.
  2. Allow your browser or file manager to install the app if Android asks.
  3. Open Miithii and allow microphone access.

Keep the app open while talking. An internet connection is required. Conversations use external speech and AI services.

This build is still being tested. Speech, pronunciation, and interruptions can fail. Assamese and Bodo content is awaiting complete native review.
