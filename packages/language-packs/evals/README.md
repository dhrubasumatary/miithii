# Language evaluation fixtures

These fixtures are research/evaluation inputs. They are not runtime language rules and they do not
contain machine gold translations.

They were migrated from `packages/language-core/test/fixtures` at
`88bc15a3aa9ae5e3f33b8cf979333adcdcc1d544`. Voice-output assumptions were updated to the current
contract: canonical `asm`/`brx`, native-script output, current Assamese address-form policy, and the
current shared Miithii persona. The fluent-speaker rubrics remain human review rubrics rather than
machine assertions.
